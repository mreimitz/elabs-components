  - avoid: Firing the destructive action immediately on click — require the AlertDialog confirm (or an undo window).
  - avoid: Making the destructive action the default-focused button — focus the Cancel/safe action first.

- Button (variant=default*|secondary|destructive|outline|outline-subtle|ghost|link · size=sm|default*|lg|icon|icon-sm|icon-lg) — Primary action trigger — the canonical way to invoke an action.
  - avoid: Two primary Buttons in the same action group — demote one to secondary/outline.
  - avoid: Button used for navigation — use a link instead (asChild + <a>, or the variant="link").
  - avoid: destructive variant for an irreversible action with no confirm step — wrap in AlertDialog.
  - avoid: Icon-only Button without an aria-label — the control has no accessible name.

- Card (interactive=true|false*) — Surface grouping related content into a bordered, padded block.
  - avoid: Card inside a Card (nested cards) — flatten; cards are not a generic wrapper.
  - avoid: Card-for-everything — use a Card only when a bordered surface is the right affordance.
  - avoid: Identical icon-tile-above-heading Card grids repeated endlessly — vary structure.

- Toolbar (orientation=horizontal*|vertical) — A dense row of controls that acts on nearby content, collapsed into ONE tab stop with arrow-key navigation between the controls.
  - avoid: Using it for the ordinary control row above a list or table — that is ViewToolbar, where every control is its own tab stop.
  - avoid: Omitting aria-label — a toolbar is one tab stop, so an unnamed one announces nothing about what it acts on.
  - avoid: Putting a text input or a link inside it — the roving tabindex swallows the arrow keys those controls need.
  - avoid: Reaching for it to attach actions to a canvas node — that is NodeToolbar in @elabs-ai/components-ai.
