# @elabs/components-editor

> Token-themed Monaco editor: CodeEditor, DiffEditor, CodeWorkspace.

Import from `@elabs/components-editor`. Part of brand-ui — see the root `llms.txt` for routing.

## Components

- CodeEditor — Monaco-backed editable code editor (controlled/uncontrolled), themed from tokens.
  - avoid: Passing Monaco a hardcoded theme — the bridge reads the active data-theme tokens; never override it.
  - avoid: Using CodeEditor for read-only display — use CodeBlock (@elabs/components-ai, Shiki) for non-editable code.
  - avoid: Forgetting the worker setup (import "@elabs/components-editor/monaco-environment") — IntelliSense is off without it.
- CodeWorkspace
- CopyButton
- DiffEditor
- EDITOR_LANGUAGES
- EditorContextMenu
- EditorToolbar
- MarkdownEditor
