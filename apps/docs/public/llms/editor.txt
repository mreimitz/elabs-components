# @elabs-ai/components-editor

> Token-themed Monaco editor: CodeEditor, DiffEditor, CodeWorkspace.

Import from `@elabs-ai/components-editor`. Part of brand-ui — see the root `llms.txt` for routing.

## Components

- CodeEditor — Monaco-backed editable code editor (controlled/uncontrolled), themed from tokens.
  - avoid: Passing Monaco a hardcoded theme — the bridge reads the active data-theme tokens; never override it.
  - avoid: Using CodeEditor for read-only display — use CodeBlock (@elabs-ai/components-ai, Shiki) for non-editable code.
  - avoid: Forgetting the worker setup (import "@elabs-ai/components-editor/monaco-environment") — IntelliSense is off without it.
- CodeWorkspace
- CopyButton
- DiffEditor — The Monaco side-by-side diff surface — the only diff in the library that can be typed into.
  - avoid: Reaching for it to READ a patch — that is DiffView in @elabs-ai/components-ai, which needs no editor engine at all.
  - avoid: Reaching for it to approve or reject hunks — that is ChangeReview, which owns the trust gate.
  - avoid: Rendering it in a jsdom unit test — it is Monaco; test the surrounding wiring and leave the editor to a browser story.
- EDITOR_LANGUAGES
- EditorContextMenu
- EditorToolbar
- MarkdownEditor
