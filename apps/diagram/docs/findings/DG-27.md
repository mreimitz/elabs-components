# DG-27 — composite interaction boundary

The reference compiler supplies real component metadata, qualified imported ids and origin
mapping. The app renders collapsed references with a stacked kind/product tile, node count
and labelled inner endpoints. Automatic layouts support authored expansion in Edit and
session-only expansion in View. Imported contents expose read-only details; changing a
reference's contents requires opening its source diagram explicitly.

Inspection uses a second, local React Flow provider and a locally compiled child snapshot.
The parent document, editor model, undo history, selection and tab remain mounted. A validated
`&into=tenant.nested` instance chain addresses nested inspection without changing the parent
workspace path. Both ordinary and presentation views provide breadcrumb navigation and an
explicit Open diagram action. The action uses the existing save/conflict-aware document API
and opens the referenced source in Edit.

Effective mutation admission is read-only while inspecting. The parent canvas is inert and
its document-level delete handler is disabled; Monaco retains its model but becomes read-only.
Document shortcuts and direct text edits share the inspection guard. Child canvases have no
write callbacks. Pure live-view routes receive no composite action provider.

Camera transitions use the existing motion tokens and reduced-motion preference. Saved
camera frames and pending transitions are invalidated by source, dependency, layout or load
revisions. Temporary expansion is discarded on a document reload and any same-document
source/dependency revision, including changes that return to earlier text. These previews and
child inspection block thumbnail publication until the authored parent is visible again.

Manual layout deliberately disables inline expansion with an explanation; drill-down remains
available. Missing, invalid or cyclic references show a recoverable inspection error. Peek
thumbnails and protected-component behavior remain outside the R1 cut.

The app composes FlowNodeCard, FlowPort, CanvasShell, InspectorPanel, Breadcrumb and Button.
React Flow's updateNodeInternals and viewport types are imported from its engine because the
flow package does not re-export those APIs. No shared package API changed.

Durable checks: `scripts/tests/composite-navigation.test.mjs` validates route grammar and
nested resolution failures; `tests/composite-interactions.mjs` exercises real UI in both themes
at desktop and phone widths, with source-byte and write-observation assertions.
